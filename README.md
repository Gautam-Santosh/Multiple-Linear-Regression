\# Multiple Linear Regression — Income Prediction



Predicting a person's \*\*income\*\* based on their \*\*age\*\* and \*\*experience\*\* using 5 different machine learning models.



\## Models compared

\- Linear Regression ⭐ (best performer)

\- Random Forest

\- Decision Tree

\- Support Vector Regression (SVR)

\- Gaussian Naive Bayes



\## How to run

1\. Clone this repo

2\. Install requirements: `pip install pandas numpy matplotlib seaborn scikit-learn joblib`

3\. Open `Multiple\_Linear\_Regression\_documented.ipynb` in Jupyter

4\. Run all cells



\## Results

| Model | R² Score |

|-------|----------|

| Linear Regression | 0.94 ✅ |

| Random Forest | 0.68 |

| Decision Tree | 0.30 |

| SVR | -4.59 ❌ |

| Naive Bayes | -1.37 ❌ |



\## Dataset

20 rows × 3 columns: `age`, `experience`, `income`
